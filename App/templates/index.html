AWS Cloud Architecture

Three-Tier Application

A single connected flow across compute, data, and storage

🖥️
Application Tier

Amazon EC2

Runs your application logic on scalable virtual servers.

🗄️
Data Tier

Amazon RDS

Managed, secure relational database with automated backups.

📦
Storage Tier

Amazon S3

Durable object storage for assets and application data.

⚡ Client requests hit EC2, which reads and writes to RDS while offloading files and backups to S3.
